## DIGITAL INDICATOR
**Page**: `/digital-indicator`
**Design & System Rules Established**:
1. **First Page / Step 1 Configuration Controls**:
   - Must be displayed right in the first page (Step 1):
     - **Calibration Mode**: `mV Calibration` (Default) vs `Load Cell Calibration`
     - **Load Cell System**: `4 Load Cell System` (Default) vs `8 Load Cell System`
     - **Current Output**: `YES` (Default) vs `NO`
2. **Current Output (mA) Logic**:
   - Table 3 in the template contains a column for `Current output mA`.
   - If Current Output is `YES`: show the `Current output mA` column in the Calibration Matrix (Step 4).
   - If Current Output is `NO`: hide/omit the `Current output mA` column in the Calibration Matrix (Step 4).
3. **Master Templates & Integrity**:
   - Master templates reside in `DOC/` and MUST NEVER be edited, modified, or overwritten:
     - `DOC/DIGITAL INDICATOR 4 LOAD CELL SYSTEM mv calibration.docx` (mV Calibration, 4 Load Cells)
     - `DOC/DIGITAL INDICATOR 8  LOAD CELL SYSTEM  mv  calibration.docx` (mV Calibration, 8 Load Cells)
     - `DOC/DIGITAL INDICATOR 4 LOAD CELL SYSTEM.docx` (Load Cell Calibration, 4 Load Cells)
     - `DOC/DIGITAL INDICATOR 8  LOAD CELL SYSTEM.docx` (Load Cell Calibration, 8 Load Cells)
4. **Hardware Serial Numbers**:
   - If 4 Load Cell System: Display serial number fields for S1, S2, S3, S4.
   - If 8 Load Cell System: Display serial number fields for S1, S2, S3, S4, S5, S6, S7, S8.
5. **Calibration Matrix (Testing Results Table 3)**:
   - Contains 12 measurement rows.
   - For 4 Load Cells: Columns are `Load on Load cell Kg/T or mV`, `LC 1`..`LC 4`, and `Current output mA` (if Current Output is YES).
   - For 8 Load Cells: Columns are `Load on Load cell Kg/T or mV`, `LC 1`..`LC 4`, `Current output mA` (if Current Output is YES), `LC 5`..`LC 8`.
6. **Remarks Section Table (Table 5 - SPAN, TARE, EXC V)**:
   - When **Load Cell Calibration** is active: Display the SPAN / TARE / EXC V table matching Table 5 of the Word document:
     - Rows: `SPAN`, `TARE`, `EXC V`
     - Columns: `LC 1`..`LC 4` for 4 LC; `LC 1`..`LC 8` for 8 LC.
   - When **mV Calibration** is active: DO NOT show this table (hidden/omitted). Only standard remarks field is shown.
7. **Calculations**:
   - Calculation formulas will be provided explicitly by user in a subsequent step. Do not inject arbitrary formulas.
